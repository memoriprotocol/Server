HeroLand 3.12.7 — Stage25: Gift и удаление неверной расстановки Map2

УСТАНОВКА
1. Остановить node server.js (Ctrl+C).
2. Сделать резервную копию Server_Full.
3. Скопировать содержимое папки Server_Full из этого архива в
   D:\HeroLand_Local\Server_Full с заменой одноимённых файлов.
4. Запустить START_SERVER.bat или открыть PowerShell в Server_Full
   и выполнить: node server.js
5. Полностью перезапустить клиент и войти заново.
Папка data и аккаунты в патч не включены, они сохраняются.
Изменять файлы клиента / Index не требуется.

GIFT
В оригинальном ShopModel.getCanGiveShopItems товары выбираются из
обычных вкладок по биту SaleType.present=64. Отдельного запроса раздела
6 при входе клиент не делает. Раньше товары имели saleType=0, а
все подарочные позиции находились только в разделе 6.
Теперь 15 скинов и 4 маунта доступны подарочному фильтру из вкладок 1 и 5.
Цены локальные, как в конфигурации сервера, не подтверждённые магазином
официального сервера. При дарении списывается presentPrice в валюте
costId, отображаемой клиентом. Повторная выдача уже имеющегося предмета
отклоняется. Исходная реализация выдаёт подарок сразу получателю;
полный цикл принятия/отклонения подарков через почту этим патчем не восстановлен.

MAP2 — ЧТО ИМЕННО СДЕЛАНО
Удалены 27 NPC с ручными координатами, 8 ручных стен и 4 моста Map10.
Удалены связанные ручные коллизии стен и предполагаемые прямоугольники воды.
Нативные декорации карты остаются под управлением клиента.
Даже старые HEROS_CITY_NPCS_ENABLED=1 / HEROS_CITY_OBJECTS_ENABLED=1
не возвращают отклонённые объекты.
Это НЕ восстановление правильного состава и расстановки NPC города.
Правильные NPC не добавлены: точные координаты ещё не получены.

ИСТОЧНИК
Проверен исходный HeroLand_Full_Client, часть z01; извлечённые файлы
проверены по CRC из центрального каталога ZIP. Клиент не изменялся.
В arena/maps/map_2, пакет 01ba3b118.json, встроена ссылка:
${server_path}/submods/ioprotocol/config/map_editor/2/scene_placements.json
Файла с таким именем в каталоге полного архива клиента нет.
Каталог префабов и CreatureScheme не доказывают, что NPC относится к Map2.
Для точной расстановки нужен оригинальный scene_placements.json для карты 2
из серверных данных этой версии или иной проверяемый источник координат.
Подробный аудит и удалённые записи: MAP2_GIFT_STAGE25_AUDIT.json.

ПРОВЕРКИ
22 целевых теста проходят (магазин, валюта, подарки, гача, запрет
неподтверждённых спавнов). Gift проверен исходной функцией фильтрации
клиента после protobuf round-trip; проверена выдача подарка по числовому UID.
Команда из Server_Full:
node --test tests/stage25-map2-gift.test.js tests/stage20-shop-2024-compat.test.js tests/stage22-recruit-water.test.js tests/stage19-safe-commerce.test.js
Исторические тесты города Stage12–24, ожидающие 39 ручных объектов,
теперь противоречат требованию использовать только подтверждённые Map2
размещения. Полный старый npm test не проходит; он не является
подтверждением этого патча. Рендер Gift в запущенном клиенте не проверен.
