SERVER STAGE40 — бой, дроп, XP, уровни и оповещения для клиента 3.12.7
===================================================================
Это следующий полный архив сервера после Stage39. Восстановление 1:1 ещё
не закончено. Клиент не изменялся. Нативные схемы/события проверены кодеком;
работа в настоящем Windows-клиенте в этой среде не проверялась.

УСТАНОВКА
1. Остановить сервер и сделать резервную копию текущего Server_Full.
2. Перенести файлы этого Server_Full поверх текущего Server_Full.
   Сохранить свою Server/data со всеми accounts.json, players.json,
   admin-state-3127.json и прочими сохранениями. В архиве чужих аккаунтов нет.
3. Запуск прежний: START_SERVER.bat или node server.js. Нужен Node.js >=20.
   Website_Full, настройки портов и путь клиента прежние.
4. Старая папка data/ в корне требует прежней миграции Stage30: не переносить
   её вручную поверх Server/data. Эти старые инструменты здесь не добавлялись.

ЧТО ДОБАВЛЕНО
- Навыки 17 видов Map2 (289 мобов + 4 босса): собственные ID/анимационные
  события, перезарядки, подготовка, выпуск, остановка и завершение.
- Серверный урон по кругу, сектору и прямоугольнику; рывки и выход из земли;
  летящие/возвращающиеся энергетические снаряды, кислотные залпы и зоны;
  вращение с интервалом, ураган, яд и запрет атаки при confused.
- Лечение союзников, поглощающий щит, усиления атаки/крита с истечением.
  Щит не лечит. Усиления обновляются без бесконечного накопления.
- Призыв четырёх настоящих мобов 1208 уровня 40 с их навыками на 18 секунд.
  Временные сущности удаляются по времени/смерти источника; наград за них нет.
- Нативные газовые зоны; частичные жизненные циклы грибных иллюзий и цветка.
  Это не означает восстановление всех их оригинальных боевых правил.
- Урон героя теперь зависит от атаки и базовых коэффициентов навыка,
  вместо постоянной цифры. Полная формула сопротивлений ещё не восстановлена.
- Дроп 293 исходных мобов/боссов Map2 через DropDeath -> DropGroup, включая
  повторные вложенные розыгрыши, независимые вероятности, диапазоны количества
  и веса Weapon/Equipment/Jewel. Нулевой Weight исключён.
- Предметы появляются на земле и подбираются обычной командой клиента.
  Сохраняются между перезапусками. Золото/алмазы идут в кошелёк, XP — в опыт.
- XP по LevelExp до 200 уровня, рост HP/атаки/других статов по PropLevels;
  экипировка применяется поверх новых базовых статов. Несколько уровней за
  одно убийство обрабатываются сразу. У героя 1 базовые HP теперь 1000,
  вместо прежней локальной константы 800.
- XP команды сохраняется одной транзакцией. Личный XP получает убийца,
  командный делится между живыми загруженными участниками в радиусе 4800
  от трупа в той же комнате. Это локальное правило распределения.
- Повторный удар по трупу не выдаёт награду. Ошибка записи откатывает
  смерть, HP, щит и изменения профилей. Повторная попытка сохраняет розыгрыш.
- Оповещения: убийство босса kill_boss; предупреждение за 30 секунд
  boss_alert; фактический респаун createBoss; подбор оружия grade>=6 или
  экипировки Star>=6 с босса get_valuable (радужные/мистические).
- Оповещение о вещи отправляется после успешного сохранённого подбора.
  Ошибка, полный рюкзак, повторный подбор и обычные вещи его не создают.
  Область оповещений — текущая игровая комната.
- Из s3.2 использован принцип оповещений, но не пакет 7.15: для 3.12
  SystemType.msg=22, а не 25. Формы событий взяты из клиента 3.12.
- Общий XP больше 2^31 передаётся отдельным unsigned updateTotalExp;
  после загрузки сцены опыт восстанавливается приватно, без утечки в команду.

РАССТАНОВКА И СОХРАННОСТЬ
Сохранены исправления Stage39: 160 деревьев и 24 колодца вне воды/очищенных
зон четырёх боссов, вся шахтная арена 1306 учитывается вместе с углами;
между колодцами не менее 2400 (фактически минимум 2736.83).
Стартовые данные четырёх боссов совпадают с исходной контрольной суммой.
Старые стены, мосты, NPC/стражи сохранены. Точную оригинальную расстановку
MainCity 3.12 этот этап не восстановил. Город 7.15 для этого не подходит.

ЧЕСТНЫЕ ОГРАНИЧЕНИЯ
- Три овцы 1210 уровня 75 не имеют точной строки DropDeath в клиенте:
  применена ближайшая существующая строка уровня 60. Это видно в аудите.
- AI выбирает навыки циклически с проверкой дальности; официальный порядок,
  условия поддержки, агро/сброс и серверная случайность ещё не восстановлены.
- Известна базовая формула из подсказки клиента. Сопротивления, уклонения,
  окончательный крит и все модификаторы урона не доказаны как оригинальные.
- Рассеивание кислоты, секундные тики яда/газа и часть времени жизни эффектов
  являются локальными решениями. Грибные иллюзии: перенос урона/правила
  ложного и настоящего гриба не восстановлены. У цветка не добавлены
  неподтверждённые усиления. Для обычных лисьих/хомячьих снарядов работает
  серверное столкновение, но сетевой визуальный контракт ещё не подтверждён.
- Смерть игрока пока использует прежнее локальное возвращение в город.
  Полные смерть/расчёт/потеря вещей/воскрешение и остальные отсутствующие
  серверные механики по-прежнему требуют работы.
- Наличие клиентских ассетов, таблиц и protobuf само по себе не доказывает
  оригинальную серверную логику. Непроверенные правила отмечены явно.

ПРОВЕРКИ И ИСТОЧНИКИ
npm run test:stage40 — эффекты/награды/пакеты/инвентарь/сохранность размещения.
npm run audit:stage40 — воспроизводимый аудит схем, дропа и исходных боссов.
Итоги общего набора и сравнение с исходным Stage39:
retail/audits/STAGE40_VALIDATION.json. Общий npm test не полностью зелёный:
в исходном Stage39 уже было 17 ошибок старых ожиданий города/структуры архива.
Новые тесты и источник каждого контракта приложены в Server/tests/ и
retail/client-reference/stage40/. Исторические README_STAGE39 и старше
описывают соответствующие этапы, а не текущее состояние Stage40.
