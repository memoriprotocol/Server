ВОДА
- На вход/выход в воду продолжает отсылаться оригинальное
  interactWithWater(enterOrExit).
- После loginLoadingFinish состояние воды синхронизируется ещё раз;
  если игрок в воде, повторяется до одного раза в 5 секунд.
- Текущее местоположение проверяется на маску воды с учётом мостов.
- Реальное переключение клиентской анимации на плавание не подтверждено:
  при необходимости нужен сам оригинальный клиент и его Console/сетевой лог.

МОБЫ
- Мобы и боссы помечаются active=true (ранее active=false).
- После загрузки запускается синхронизация окружающих сущностей.
- Приоритет у ближайших объектов, порциями не более 16 на одно событие.
- Радиус обнаружения 4800, переданные объекты учитываются по категориям.
- Для отладки: set HEROS_ENV_VERBOSE=1 до запуска сервера:
  в консоли появятся сообщения [ENV SEND] с количеством мобов.
- Отрисовка в клиенте не доказана без проверки нативного client asset loader:
  серверные prefab_path всё ещё нужно проверять по файлам самого клиента.

УСТАНОВКА — ПАТЧ
1. Закройте игру и сервер. Создайте копию папки Server_Full.
2. Распакуйте PATCH_STAGE28.zip и скопируйте содержимое папки
   Server_Full поверх D:\HeroLand_Local\Server_Full с заменой.
3. НИЧЕГО из data/ не заменяйте: там аккаунты/персонажи/админка.
4. Запустите D:\HeroLand_Local\Server_Full\START_SERVER.bat
   либо откройте PowerShell в папке и запустите node server.js.
5. Переподключитесь к игровому миру (не просто обновите страницу сайта).
6. Проверьте все 4 выхода, все 4 внешние safe-zones и воду вне мостов.
7. Для координат правьте JSON при остановленном сервере, затем перезапуск.
