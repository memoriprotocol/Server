МУМИЯ: СКАРАБЕИ ВМЕСТО МГНОВЕННОГО ОБЩЕГО УДАРА
Native6009 на Map2 требует10боевого уровня, ждёт200мс castPoint и выпускает
5+floor(maxHP/1000) скарабеев. Число фиксируется при принятии F.
Все3звезды/3скина701/702/703 используют родной объект1023 с ud.skinID,
а оригинальный обработчик выбирает их собственные модели.
Направление берётся из последнего курсора в момент начала выпуска.
Попадание не теряется при цели вплотную. Перемещение учитывает пересечение
отрезка, тела противника и существующие препятствия; стены города не менялись.
Native скорость1500, дальность2000, активное existence2000мс.
При контакте/истечении сервер отправляет ровно одно scarabBomb123:
исходный клиент останавливает движение модели, играет skill и звук взрыва.
Повреждение/крит/сопротивления/убийство/XP/дроп проходят общий прежний обработчик.

ЛЕЧЕНИЕ И ПАССИВ
На2/3звезде native DamageHealth даёт300 HP. Здесь лечение выполняется один раз
за завершённый активный взрыв, не за каждого врага и не умножается критом.
Лечение при пустом взрыве тоже включено как локальная трактовка; условие
лечения retail-сервера исходным клиентом не доказано.
На3звезде положительный урон непосредственно по HP от моба/босса запускает
одного скарабея6023. Удар только в щит, защита,0урона и смерть его не запускают.
F не перезапускается и его cooldown не оплачивается повторно. Направление — курсор.
Расхождение источника сохранено: описание/args6009 указывает1500мс пассива,
таблица6023 указывает2000мс. В этой реализации выбрано1500мс по описанию.
Пассив использует собственные поля damaga5000/atkargs70 для3звезды; формула
общего серверного расчёта реконструирована. Native tooltip-функция читает args,
которые у6023 пусты, поэтому сама по себе не подтверждает эту формулу.
Пассив не лечит: у6023 нет healRate. Все retail-триггеры вне monster-effects
(например полный PvP/самоурон/другие периодические источники) не объявлены готовыми.

НАДЁЖНОСТЬ
Отдельная runtime-задача, ограничение64живых+зарезервированных объектов,
до6созданий за наблюдаемый тик. Переполнение отклоняется до оплаты F;
полная принятая группа не обрезается лимитом. Смерть/смена героя, скина, жизни,
мира, комнаты или карты очищают старые объекты; ошибка сохранения убийства
не повторяет успешные контакты. Повтор доставки отправляет текущие HP,
не выполняя повторно лечение, урон или награды. Новый наблюдатель получает123
для уже взрывающегося объекта через обычную очередь видимости.

ГРАНИЦЫ РЕКОНСТРУКЦИИ
Расположение группы поперёк курса, выпуск пачками, геометрия полёта/области,
направление пассива, трактовка лечения/6023 и порядок эффектов локальные.
Минимум100мс до123 и1секунда существования взрыва — запас на загрузку модели,
а не подтверждение готовности Cocos/ассетов. Медленный клиент может загрузить
модель позднее; живая Windows-отрисовка этой сборки не проверена.
Ядовитый туман1024 пока НЕ восстановлен: в исходном классе нужны prefab_path
и poisonFogDuration, но связь с конкретным ресурсом/уроном не доказана.
Наличие args.duration5000/size400 у3звезды не подменяется выдуманным туманом.
PvP и все карты для нового поведения Мумии не заявлены готовыми.
