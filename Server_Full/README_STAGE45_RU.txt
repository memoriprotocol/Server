STAGE45 — ГОРОД MAP2 И ОТПРАВКА ОБЪЕКТОВ, HERO'S LAND 3.12.7
Контрольная сборка восстановления. Полное восстановление 1:1 ещё НЕ завершено.
Содержит предыдущие исправления Stage42–44. Клиент и Index не изменены.

УСТАНОВКА
1. Остановить сервер и сайт. Сохранить резервную копию баз игроков.
2. Скопировать Server_Full поверх установленной папки сервера.
3. Website_Full содержит восемь накопленных файлов исправлений сайта Stage44.
   Скопировать их поверх существующего сайта; остальные файлы сохранить.
4. Если запуск сообщает о старых корневых lib/config/data, сначала выполнить
   node Server/tools/migrate-stage30.js — это только план, без изменений.
   Затем MIGRATE_STAGE30.bat (или та же команда с --apply).
   Скрипт переносит старые папки в retail/migration-backups и копирует старые
   сохранения в Server/data. Различающиеся существующие сохранения блокируют
   перенос до изменений. Скрипт не запускается автоматически. При ошибке
   ввода-вывода проверить сообщение и сохранённые исходные данные.
5. Запустить START_SERVER.bat и сайт; для страницы сайта Ctrl+F5.
Архив не содержит баз игроков, аккаунтов, платёжных ключей или клиентского Index.

ИСПРАВЛЕНИЯ ЭТАПА
— При HEROS_CITY_OBJECTS_ENABLED=0 отключённые городские стены больше
  не остаются в проверках пересечения строительства и AI. Пять родных
  безопасных областей сохраняются.
— При синхронной ошибке кодирования/отправки городского пакета очередь
  объектов и счётчики сохраняются. Есть повторная попытка с ограничением
  частоты и диагностикой ошибки. Успешная постановка пакета в транспорт
  не доказывает отрисовку на клиенте; отдельного ACK объектов здесь нет.
— Отправка по умолчанию deferred согласована с диагностикой. После загрузки
  отправляются до двух объектов за пакет, не чаще 220 мс и при новом кадре
  клиента. Для старого сигнала загрузки остаётся медленный fallback 1/850 мс.
— Добавлена защита от точного повторения клиентского декора по prefab/x/y.
  Она действует только на необязательные записи decor. Стены, мосты и NPC
  текущей операторской расстановки сохраняются.
