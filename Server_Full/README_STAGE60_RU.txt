УСТАНОВКА — НУЖНЫ ОБНОВЛЕНИЯ СЕРВЕРА, САЙТА И ДОПОЛНЕНИЯ КЛИЕНТА
1.Останови игру/сервер/сайт. Сделай резервную копию всех трёх установок.
2.Скопируй Server_Full из архива поверх установленного Server_Full.
  Сохрани Server/data, .env, приватные настройки и секреты. В архиве данных нет.
3.Скопируй содержимое Website_Full поверх СВОЕГО полного сайта Website_Full.
  В архиве Website_Full — накопленный ПАТЧ, не новый полный исходник сайта.
  Сохрани data, local.config.json, .env, платёжные ключи и настройки домена.
  sharedSecret сайта и HEROS_WEB_SHARED_SECRET игрового сервера должны совпадать.
  paymentSecret / LOCAL_WEB_PAYMENT_SECRET для подписи заказа тоже должны совпадать.
  Для боевых покупок тестовый режим должен оставаться выключенным в настройках.
4.Скопируй СОДЕРЖИМОЕ Client_Payment_Addon в корень установленного клиента.
  Обновляется resources/app/cocosExport/web-desktop/local-bootstrap.js;
  папку Client_Payment_Addon не вкладывай отдельным уровнем. Index.js не заменяй.
5.Запусти сайт прежней командой; сервер START_SERVER.bat либо node server.js
  из Server_Full. Полностью перезапусти клиент и войди снова.
6.На auth-порту10000: /status (0.38.0-stage60-world-events-payments),
  /diagnostics/map2-combat, /diagnostics/locations.
