ОБМЕН ОРУЖИЯ И ЭКИПИРОВКИ У NPC415
Родной клиент открывает у supplyOffice415 окно CCExchangePanel. Оно отправляет
exchangeItem89 со списком UUID и показывает ОПЫТ из WeaponScheme/EquipmentScheme.Exp.
Раньше сервер пропускал эту команду. Теперь выбранные вещи удаляются, начисляется
ровно этот боевой XP, пересчитываются уровень/статы и приходят родные события.
Это обмен на ОПЫТ, не на золото: ItemScheme.price здесь не используется.
Все286 значений оружия и255 значений экипировки сопоставлены с данными клиента.
Белые стартовые вещи с Exp=0 дают0XP, как в родном предварительном расчёте.
Высокая редкость использует существующее подтверждение родного окна; Index не менялся.

НАДЁЖНОСТЬ / ПРОГРЕСС
Удаление вещей, XP, журнал текущей жизни, квест18/уровень и задания пропуска8/9
записываются вместе. Один плохой/чужой/заблокированный UUID отменяет всю пачку.
Ошибка записи ничего не отнимает. Повтор по уже удалённому UUID не даёт награду снова.
При ошибке отправки сохранённый обмен остаётся успешным; обновления сумки/XP
повторяются без нового начисления. Очередь в памяти, после перезахода состояние
восстанавливается из сохранения. Старые эффекты не переходят в другой аккаунт/жизнь.
Боевой уровень по-прежнему сбрасывается при завершении жизни/перезаходе по прежним
правилам; этот XP не превращается в постоянный уровень героя.
Подключены SellWeapon8/SellEquipment9 пропуска и SellItem18(включая квест2350 новичка).
Ежедневные задания категории2 целиком ещё не восстановлены.

БЛОКИРОВКА ПРЕДМЕТОВ
Подключена родная lockItem162:Ctrl+левый клик по вещи в игровом интерфейсе.
Сохраняется extInfo.il=1/0, остальные свойства сохраняются. Заблокированное нельзя
обменять или выбросить; сортировка в игре/лобби оставляет его в своей ячейке.
Сортировка остальных вещей остаётся прежней серверной, не полной native-сортировкой.
Произвольное изменение userdata/WeaponLv/цены с клиента не добавлено.

УСЛОВИЯ И ОГРАНИЧЕНИЯ
Работает в Map2 main/rookie рядом с существующим NPC415, живым персонажем.
У NPC в оригинальном import подтверждён сенсор600; используется прежняя добавка
радиуса игрока50*SkinScale. Пачка1..128 уникальных UUID, оружие/экипировка по1шт
из сумок1/3. Быстрые слоты/надетое/склад/текущее оружие сначала нужно освободить.
Неизвестный уровень оружия/отсутствующий Exp отклоняются без потери вещей.
Эти защитные ограничения и крайние случаи — реконструкция сервера, не retail-код.
Старая sellItem71 и панель торговли ресурсами не подменены этим обменом и остаются
незавершёнными. Не восстановлены события2..9 и5 типов настроенных заданий пропуска:
JionEvent/JionTrial/CrossLobbyMap/HuntingPoint/UnlockMystery.
Все19 локаций/прочие механики остаются в накопленном списке работ.
