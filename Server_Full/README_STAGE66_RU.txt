СПАРТАНЕЦ6013: ВСЕ3 ЗВЕЗДЫ
Прежний общий обработчик ошибочно делал короткое поле в точке курсора.
ТеперьF включает/выключает стойку. Удары идут вокруг текущей позиции героя каждые1500мс,
каждый импульс расходует15 выносливости. При нехватке стойка выключается без нового урона.
Звёзды2/3 накладывают роднойstun_9(241), звезда3 даёт30% снижения входящего PvE-урона.
Родные buff586/705 используют текущий скин. Стойка продолжается после прежних5сек,
пока включена/есть выносливость. Смерть, выход, смена героя/карты/комнаты, сейф-зона
очищают её. Ручное выключение доступно до истечения стартовогоCD.
Сохранён порог10 боевого уровня дляF.
Первая волна через1500мс, отсутствие пачки волн при лаге, CD5сек после выключения,
wire-длительность визуальных buff2147483647мс, лимит128 целей/импульс и retry250мс —
локальные политики восстановления. Retail-серверного исходника этих правил нет.
Если сохранение смерти цели не прошло, оплаченные контакты/расход выносливости
не повторяются при retry. Появившаяся новая жизнь цели не получает старый контакт.

повторением паладина. Действующая общая блокировкаF при confused192 сохранена:
этот этап не вводит неподтверждённое самоочищение из запрещённого ввода.

МОНАХИНЯ6006: ВСЕ3 ЗВЕЗДЫ
Родной castPointTime200мс теперь отделяет нажатиеF от лечения/skillCast/VFX.
Звёзды2/3 дают начальное лечение; периодическое лечение используетHP монахини,
зафиксированное на выпуске. Отмена до выпуска работает при смерти, смене героя,
карты/комнаты, входе в сейф-зону, блокировке каста и слишком позднем выпуске.
Периодические задания не продолжаются в другой комнате/карте и не лечат поздно
после завершения. Третья звезда теперь даёт союзникам30% снижения PvE-урона6000мс
с роднымbuff403. Учитывается жизнь/комната/карта источника; два одинаковых эффекта
не суммируются и не удаляют ещё действующий эффект другого источника.
Состав группы/радиус определяются прежним союзным фильтром, дополненным проверкойкарты.
СнимокHP/момент состава группы/исчезновение ауры при потере источника — реконструкция.
Пассив50% усиления лечения оружием/снаряжением пока НЕ подключён.

сохраняет прежний обработчик. Точные retail-фильтры вампиризма пока не подтверждены.

ПЕРЕЗАРЯДКИ И17 ВАРИАНТОВ ОРУЖИЯ С ЗАРЯДАМИ
Родной CCSkillCDComp использует отдельный skillCDUpdate, а не толькоuseSkill.skillCD.
Добавлены fixedInfo, useMillis, skillLv и обязательныйchargeInfo: клиентский метод
читаетchargeInfo без проверки. Реальная серверная скидка теперь попадает в отсчётUI.
СинхронизацияCD отправляет фактическую звезду героя и сохранённую длительностьCD
с момента нажатия. Изменение скидок после каста не укорачивает уже начатый одиночныйCD.
Для17 вариантов родные2/3 заряда теперь расходуются отдельно, затем восстанавливаются.
Клиент получает оставшееся количество/времена использования; обновление по таймеру
передаётся тем же роднымskillCDUpdate. Синхронизация не создаёт атаку и не тратит стамину.
Восстановление каждого заряда независимо через егоCD и минимум200мс между нажатиями —
явная локальная политика. Полные эффекты этих17 навыков остаются частичными.
СписокID/зарядов/родныхCD —STAGE66_HERO_MECHANICS.json вretail/audits.
