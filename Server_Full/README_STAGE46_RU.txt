STAGE46 — НАТИВНЫЙ RMB ОРУЖИЯ, КОЛЛЕКЦИИ, МАУНТЫ И СТЕНЫ STAGE44
Hero's Land, клиент 3.12.7. Контрольная сборка, НЕ завершённое восстановление 1:1.
Содержит предыдущие исправления Stage42–45 и изменения настоящего этапа.
Клиентский Index и исполняемые файлы клиента не изменяются.

КУДА КОПИРОВАТЬ И КАК ЗАПУСКАТЬ
1. Остановить сервер и сайт. Сделать резервную копию своих баз игроков.
2. Папку Server_Full из архива скопировать поверх установленной Server_Full.
   Сохранить свои Server/data и приватные настройки: в архиве баз игроков нет.
3. Website_Full — восемь накопленных файлов исправлений сайта Stage44,
   без новых изменений Stage46. Скопировать поверх существующего сайта,
   остальные файлы сайта/лаунчера сохранить.
4. Запустить START_SERVER.bat или node server.js из Server_Full.
   В начале лога появится [STAGE46] Native RMB: CommandUseSkill/skill2.
   /status должен показывать 0.24.0-stage46-native-rmb-collections.
5. Перезапустить сайт и полностью перезайти в игру. Старые карточки и
   предметы скинов из Item будут перенесены в коллекции один раз при входе.
6. Только если сервер сообщает STAGE30_MIGRATION_REQUIRED: остановить
   сервер/сайт, выполнить node Server/tools/migrate-stage30.js для плана,
   затем MIGRATE_STAGE30.bat. Старые папки сохраняются в резервной копии,
   различающиеся сохранения не перезаписываются автоматически.
Для игровых проверок серверных команд нужен текущий персонаж в мире,
а не только открытая веб-страница. Скилы героя доступны с 10 боевого уровня.

ГЛАВНАЯ ПРИЧИНА НЕРАБОТАВШЕГО RMB
Оригинальный CCInputCtrlComp.onMouseDown отправляет на правую кнопку:
CommandCannonRotateTo, затем CommandUseSkill (команда 6), id=Weapon.skill2.
Сервер ошибочно считал CommandUseSkill только обычной атакой и отвергал
такой ID. Предыдущее описание RMB как команды 11 было неверным. Команда
11 в клиенте предназначена для экипировки. Исправлен именно нативный пакет;
старый локальный вызов через 11 оставлен как совместимый алиас.
Проверка выполняет настоящий обработчик мыши из клиента и передаёт его
пакеты в живой серверный обработчик кадра. Сервер создаёт видимый тип
снаряда 8. Проверено принятие всех 226 родных weapon.skill2 через команду 6.
Это подтверждает маршрутизацию, а не полное выполнение всех специальных
механик каждого из 226 умений.

ВИЗУАЛ И ДЕЙСТВИЕ ОРУЖЕЙНЫХ УМЕНИЙ
— Перед skillCast добавлена нативная фаза skillCastPoint; syncSkillCD
  больше не уходит в неизвестную команду и не тратит выносливость.
— Площадные направленные умения с skillRange=2 наносят урон вокруг
  позиции курсора, а не ошибочно вокруг персонажа.
— Добавлены собственные CCEntityOf/VFX для 40 вариантов в 11 семействах:
  зелье ведьмы, молот Тора, малая чёрная дыра, ледяной столб, ледяное копьё,
  ядовитый дротик, кактус, клешни, меч стража, рождественское дерево и фонарь.
  Использованы 28 родных prefab с проверкой CRC исходного ZIP и SHA256 import.
  Каждому обработчику передаются его обязательные userdata: координаты
  броска, радиус, duration/campID, scale, stage, ownerID и прочие читаемые поля.
  Объекты входят в снимок комнаты и удаляются по времени/смерти/выходу.
— SELF/TEAMMATE targetBuff теперь выдаются игроку/союзникам. Подключены
  серверные изменения скорости, критического урона и мгновенного лечения;
  эффект и серверная характеристика корректно снимаются по окончании.
— Исправлен разбор полноширинного двоеточия в родных args слизи.
Сложные фазы меча стража, заряды, притягивание, все особые призывы/пассивы,
все визуальные семейства и точные формулы ещё НЕ восстановлены целиком.
Для меча стража добавлен начальный визуальный этап, не вся цепочка.
