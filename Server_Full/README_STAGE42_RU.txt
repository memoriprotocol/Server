УСТАНОВКА
Закрыть сервер и сайт. Распаковать Server_Full поверх своей папки сервера.
Website_Full в архиве содержит только изменённые файлы сайта: скопировать
их поверх существующего Website_Full. Остальные файлы сайта сохраняются.
Архив не содержит accounts.json, players.json, персональные данные сайта,
платёжные ключи или новый установщик лаунчера. После копирования запустить
сервер и сайт, обновить веб-страницу с очисткой кэша (Ctrl+F5).

НЕЗАВЕРШЁННОЕ / ЧТО НЕЛЬЗЯ СЧИТАТЬ 1:1
- AI пока использует прежний упрощённый выбор цели/патруль, родные навыки
  Stage40. Полное поведение/переходы/агрессия/возврат ещё не восстановлены.
- F/RMB по-прежнему требуют реализации всех настоящих эффектов, призывов,
  ловушек, трансформаций, пассивных эффектов и специальных снарядов.
- Уязвимости боссов взяты из PropLevels: 1305 яд,1302 гром,1306 лёд,1307 огонь.
  Числовая кривая сопротивления — локальная, на основе resistantExpression;
  оригинальная серверная формула из клиента не извлечена.
- Восемь типов событий2–9 не имеют восстановленных параметров сервера/наград.
  Переключатели отмечены как требующие настройки. Полноценные ивенты НЕ готовы.
- Принудительное включение пропуска работает на сервере. Клиентский
  PassManager проверяет даты упакованной таблицы, поэтому закрытый сезон
  может остаться заблокирован в UI. Изменение Index здесь не применяется.
- Не все таланты/особые способности маунтов и ездовые петы работают.
- Точки береговой рыбалки, выбор между двумя группами улова, количество1,
  период12с (по циклу UI) — локальная политика. Веса/XP из таблицы клиента.
  Эффекты особых удочек и оригинальные места FishPond пока не восстановлены.
- Визуальное удаление подписей дропа/появление снарядов/анимации не проверены
  в Windows Cocos-клиенте. Пройдены серверные/протокольные проверки.
- Восстановление городских объектов и всех прочих механик продолжается.
