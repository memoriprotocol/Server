WINTERTIDE — ОБЫЧНАЯ ЛЕДЯНАЯ АТАКА
Подключены6 вариантов оружия618300/618301/618302/618303/618304/618350.
Нативные skillID3209/6183011/6183021/6183031/6183041/6183501.
Раньше эта обычная атака сразу выдавала урон в радиусе вокруг героя.
Теперь200мс подготовки по castPointTime, затем родная ледяная сущность
iceStaffAttack1062 в точке курсора. Она показывает предупреждение500мс,
после чего сервер рассчитывает один удар и родное замедление30% на2000мс.
В обычном50мс цикле: нажатие0 -> предупреждение200 -> попадание700мс.
При задержке тика выпуск/попадание происходят на первом подходящем тике;
телеграф не сокращается для компенсации задержанного выпуска.
Радиусы300/360/600, масштаб1/1.2/2 и максимальная дистанция2100 берутся
из SkillScheme. В родном индикаторе CIRCLE диаметр равен2*effectSize[0].
Время500мс подтверждено аргументом delayTime и чтением его в обработчике
клиента. Используется исходный префаб bingjinglingfazhang/prefab/attack.

Точка выбирается по текущему курсору и положению героя после подготовки,
затем остаётся на месте. Противник может успеть выйти из зоны; вошедшая
цель может попасть под удар. Новые цели после самого попадания повторно
не бьются: duration1000мс не превращён в периодический урон.
LMB/CommandAttack/удержание LMB/E используют одну подготовку. WASD не меняется.
Выносливость4 и CD списываются один раз. Принятый взмах переживает
отпускание кнопки; смена оружия/героя, блокировка, смерть/сейф-зона до
выпуска отменяют его без возврата цены. Уже выпущенная зона переживает
смену оружия и портал внутри Map2; её координаты не следуют за игроком.
Защищённые цели не получают урона. После смерти/выхода/смены мира эффект
очищается. Позднему наблюдателю передаётся оставшееся время предупреждения.

Повтор сохранения убийства связан с конкретной жизнью цели. Успешные
контакты не получают ещё один урон/XP; неуспешные повторяются250мс,
пока живёт зона. При повторе выбранная ранее цель могла уже передвинуться;
урон берётся по текущим боевым свойствам. Это местная политика надёжности.
При ошибке удаления сущность убирается последующей синхронизацией видимости.
