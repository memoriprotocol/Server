Основа: проверенный архив Stage57. Приоритет Map2 и общие механики.

ОБЫЧНЫЕ БЛИЖНИЕ АТАКИ
88 вариантов оружия /87 ID обычного normalAttack69 получают подготовку
по родному castPointTime:100,150,200,250,350,400,450,500мс. При нажатии
больше нет мгновенного урона для этих вариантов. В момент контакта берутся
текущие курсор, положение героя и цели. Прямоугольная/секторная дальность
остаётся по effectSize конкретного навыка; цели вплотную доступны даже
при пересечении центра героя. Перемещение WASD атакой не изменяется.
LMB, CommandAttack, удержание LMB и E используют эту подготовку.
Отправляются родные useSkill/skillCastPoint, затем skillCast и обычные
попадания beHurt/subHP, крит/OnHit/XP/дроп. Смена оружия/героя/мира,
смерть, сейф-зона и блокирующее состояние отменяют ожидающий удар.
Выносливость и CD списываются один раз при принятии; отмена их не возвращает.
Принятый взмах сохраняется после отпускания кнопки. Портал/смерть чистят очередь.
При ошибке сохранения награды повторяется только нерассчитанная цель;
уже успешные контакты не получают повторного урона/XP.

Границы реализации:16 ожидающих ударов, крайний срок release+1000мс,
повтор250мс; это местные ограничения сервера. Сектор выбирается один раз
при выпуске; при повторе сохранения прежняя цель может уже уйти, но связь
с её конкретной жизнью сохраняется. Параметры урона берутся при расчёте.
Точные retail-хитбоксы/темп анимации, особые пассивы, distanceDamFac,
прочие типы обычных атак и все активные навыки этим этапом не завершены.
Нулевой castPoint3011 остаётся мгновенным. Террейн/стены новых проверок
линии удара не получили; существующая геометрия сохранена.

УДЕРЖАНИЕ АГРА
Исправлена проверка HateTime до обновления контакта с близкой целью:
после задержанного тика моб больше не забывает игрока, который рядом.
Для уже принятой цели Map2 временное отсутствие environmentSeen не сбрасывает
агр. Первое автоматическое обнаружение по-прежнему ждёт подтверждения
видимости, чтобы очередь появления не создавала новые невидимые атаки.
WalkRange больше не подставляется как предел боя: для обычных мобов это
давало800 единиц вместо независимого предела преследования.
Явные положительные GuardRange/FixedRange сохранены; при их отсутствии
используется местный fallback max(2000,SeekRange,ChaseRange).2000 не является
найденной retail-константой. Назначение GuardRange как home-leash тоже
серверная реконструкция по полям клиента, а не исходный серверный AI.
Новый удар внутри предела дома прерывает возврат и включает ответный бой.
Снаружи предела это не позволяет увести босса через всю карту.
Настоящая потеря цели, её смерть, сейф-зона, отключение/загрузка и истечение
HateTime вдали от контакта по-прежнему запускают возврат. HateTime берётся
из MonsterContent, для17 Map2 CID это10000мс. AiType мирных мобов сохранён:
они отвечают на удар, а не становятся все автоматически агрессивными.
Полная таблица угроз, скрытность, навигация/особые состояния и исходные
смысл/взаимодействие всех ChaseRange/ChaseTime не восстановлены.
Диагностика /diagnostics/map2-combat показывает причины возврата.

ПОСТЕПЕННОЕ ВОССТАНОВЛЕНИЕ МОБОВ И БОССОВ
Убрано прежнее мгновенное HP=maxHP при завершении возврата домой на Map2.
После потери цели восстановление начинается с задержкой и идёт шагами,
продолжаясь после возвращения на место. Новый противник/входящий урон
останавливает его. Смерть не запускает лечение; респаун создаёт новую жизнь
с полным HP по прежним правилам. После лага/пустой комнаты нет накопленного
одномоментного отхила за пропущенные секунды. HP отправляется родным addHP.
Ошибка доставки лечащего события сохраняет коррекцию текущего setHP;
повтор не рисует ещё одно начисление и не возвращает старое HP после урона.

Точные10% и1с НЕ подтверждены клиентом. Сейчас это явно временное правило:
Server/config/map2-monster-recovery-3127.json
maxHPPercent=10, intervalMs=1000. После изменения перезапусти сервер.
Клиент содержит Buff70 «лечение до полного HP», args[8], но связи этого
баффа с потерей цели/возвратом не найдено.8 не объявлено процентом/интервалом.
Политики старта лечения/прерывания тоже реконструированы; не считаются1:1.
Изменение действует для мировых мобов/боссов Map2, не для призывов.

1. Останови сервер. Сделай резервную копию установленного Server_Full.
2. Скопируй содержимое Server_Full из этого архива поверх своего Server_Full.
   Сохрани свои Server/data, .env, приватные настройки/секреты.
   Папка Server/data в архиве пустая: аккаунты игроков не включены.

4. Полностью выйди из игры и зайди снова. Клиентские файлы не заменяй.
